Rekap otomatis dari Google Form — tarik data langsung dari Sheets.

Belum terhubung — memakai data contoh di bawah. Tempel URL Web App untuk menarik data terbaru dari Google Form.
Belum punya URL Web App? Lihat cara membuatnya
  1. Buka Google Sheets hasil Form Anda.
  2. Menu Extensions → Apps Script.
  3. Hapus kode default, paste kode Code.gs yang sudah disiapkan.
  4. Klik Deploy → New deployment → pilih tipe Web app.
  5. Execute as: Me, Who has access: Anyone → klik Deploy, lalu izinkan akses.
  6. Copy URL yang muncul (diakhiri /exec) dan tempel di kotak atas.
